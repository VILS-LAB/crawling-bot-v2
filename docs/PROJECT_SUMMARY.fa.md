# ربات خزنده نسخه ۲ - خلاصه پروژه

## مروری بر پروژه

این پروژه یک مهاجرت کامل از یک ربات خزنده از Arduino به PlatformIO است که شامل ویژگی‌های زیر می‌باشد:

- معماری تمیز، ماژولار و مبتنی بر کتابخانه
- نمایشگر OLED به جای LCD
- MPU9250 AHRS (9-DOF IMU) به جای سنسور اولتراسونیک
- پشتیبانی کامل از یادگیری تقویتی (قالب آماده)

## ویژگی‌های کلیدی

### ✅ تکمیل شده

- **معماری ماژولار**: ۵ کتابخانه جداگانه با مسئولیت‌های مشخص
- **نمایشگر OLED**: صفحه نمایش ۱۲۸x۶۴ پیکسلی با پشتیبانی گرافیکی
- **9-DOF AHRS**: اندازه‌گیری کامل اینرسی با MPU9250
- **کنترل سروو**: حرکت نرم و ردیابی موقعیت
- **WiFi و OTA**: به‌روزرسانی بی‌سیم با نمایش پیشرفت
- **بررسی سلامت**: تأیید خودکار سیستم در زمان راه‌اندازی
- **مستندات جامع**: ۶ فایل markdown که تمام جنبه‌ها را پوشش می‌دهند

### 🔄 قالب آماده

- **ماژول آموزش**: رابط آماده برای پیاده‌سازی یادگیری تقویتی

## کتابخانه‌ها

### ۱. کتابخانه Display

- پوشش درایور OLED SSD1306
- رندر متن در هر موقعیتی
- نوار پیشرفت برای OTA
- API ساده برای عملیات رایج

### ۲. کتابخانه AHRS

- یکپارچه‌سازی سنسور 9-DOF MPU9250
- شتاب‌سنج، ژیروسکوپ، مگنتومتر
- جهت‌گیری (roll, pitch, yaw)
- نمایش کواترنیون
- تشخیص حرکت
- ردیابی جابجایی
- حس‌گر دما
- پشتیبانی کالیبراسیون

### ۳. کتابخانه ServoControl

- کنترل ۲ موتور سروو
- **هر حرکت رمپ‌دار است** (پروفایل ذوزنقه‌ای): بدون پرش لحظه‌ای، بدون رد شدن از هدف
- **محدوده نرم** روی هر هدف و هر گام پروفایل اعمال می‌شود
- **ردیابی موقعیت**: هدف جدید همیشه از موقعیت واقعی شروع می‌شود
- `moveDownTo()` / `moveUpTo()` غیرمسدودکننده + `update()`، یا توابع مسدودکننده
- تنظیم زمان اجرا: `setSpeed()`، `setAccel()`، `setDownLimits()`، `setUpLimits()`
- موقعیت‌های از پیش تعریف شده (اولیه، تست)
- راهنما: [SERVO_SAFETY.fa.md](SERVO_SAFETY.fa.md)

### ۴. کتابخانه Network

- راه‌اندازی WiFi Access Point
- SSID اختصاصی ربات (ESP32-AP-{number})
- مدیریت به‌روزرسانی OTA
- مدیریت شماره ربات (EEPROM)
- تسک FreeRTOS برای OTA غیرهمزمان
- یکپارچه‌سازی با نمایشگر برای نمایش وضعیت

### ۵. کتابخانه Training

- قالب برای پیاده‌سازی RL
- رابط‌ها برای آموزش/یادگیری
- جای‌بان‌های ذخیره/بارگذاری مدل
- آماده برای الگوریتم شما

## نیازمندی‌های سخت‌افزاری

- **MCU**: ESP32-S3-DevKitM-1
- **Display**: OLED 0.96" SSD1306 (I2C, 0x3C)
- **IMU**: MPU9250 (I2C, 0x68)
- **Actuators**: 2x Servo Motors (GPIO 32, 33)
- **Power**: USB-C + منبع تغذیه خارجی ۵ ولت برای سروو‌ها

## نیازمندی‌های نرم‌افزاری

- PlatformIO Core یا IDE
- Python 3.x (برای PlatformIO)
- درایورهای USB (CH340/CP2102)

## شروع کار

1. **سخت‌افزار**: سیم‌کشی OLED، MPU9250 و سروو‌ها
2. **نرم‌افزار**: کلون مخزن، نصب PlatformIO
3. **ساخت**: `pio run`
4. **آپلود**: `pio run --target upload`
5. **پیکربندی**: تنظیم شماره ربات از طریق سریال (۱-۸)
6. **تست**: مشاهده بررسی سلامت روی نمایشگر OLED
