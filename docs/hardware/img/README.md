# Photographs

Images referenced by the documentation. Keeping them here (instead of in `docs/`)
means the docs can be rebuilt without touching binary assets.

## Expected files

These names are already referenced by the documentation; adding the image is all
that is needed to make the link resolve.

| File | Used by | Should show |
|---|---|---|
| `robot-overview.jpg` | [README.md](../../../README.md), [HARDWARE.md](../../HARDWARE.md) | the assembled robot, three-quarter view |
| `wiring.jpg` | [HARDWARE.md](../../HARDWARE.md) | harness, connectors, servo power |
| `oled-pages.jpg` | [ARCHITECTURE.md](../../ARCHITECTURE.md) | the display pages |
| `calibration-pose.jpg` | [CALIBRATION.md](../../CALIBRATION.md) | a robot in one of the six accel positions |

## Rules

* JPEG or PNG, ≤ 400 KB each, long edge ≤ 1600 px.
* No personal information in frame; crop out laptops, names and faces.
* Name files for what they show, in kebab-case.
