> 🎓 **یک ربات خزنده هوشمند برای درس هوش مصنوعی دانشگاه علم و صنعت ایران**  
> دانشجویان الگوریتم‌های یادگیری تقویتی را پیاده‌سازی می‌کنند تا به ربات حرکت خودکار بیاموزند.

![Crawling Bot V2](docs/img/robot-overview.jpg)

## مروری بر پروژه

یک پلتفرم رباتیک عملی که در آن دانشجویان هوش مصنوعی تئوری **یادگیری تقویتی (RL)** را روی سخت‌افزار واقعی پیاده‌سازی می‌کنند. این ربات شامل میکروکنترلر ESP32، سنسورهای حرکتی ۹ درجه آزادی، محرک‌های سروو و معماری نرم‌افزاری ماژولار است که برای پیاده‌سازی آسان RL طراحی شده است.

**ویژگی‌های کلیدی:**

- 🧠 قالب آماده برای کدنویسی RL در `lib/Training/`
- 🎮 مجموعه کامل سنسورها برای مشاهده حالت (AHRS با ۹ درجه آزادی)
- 🔧 دو موتور سروو برای اجرای اقدامات
- 📡 WiFi + OTA برای توسعه بی‌سیم
- 🖥️ نمایشگر OLED برای بازخورد لحظه‌ای

**چه چیزی آن را خاص می‌کند:**

- پل ارتباطی بین تئوری و عمل با سخت‌افزار واقعی
- کتابخانه‌های ماژولار پیچیدگی سخت‌افزار را مدیریت می‌کنند
- تمرکز روی پیاده‌سازی الگوریتم RL
- تکرار سریع با به‌روزرسانی‌های OTA

## برای دانشجویان

### سفر پروژه ۳ فازی شما

**فاز ۱: آشنایی با سخت‌افزار** (هفته ۱)

- آپلود کد پایه و تست تمام اجزا
- نمایش "Hello World" توسط ربات
- پیاده‌سازی حرکت ساده دست تکان دادن "خداحافظی"
- ✅ تأیید صحت عملکرد سخت‌افزار

**فاز ۲: ساخت الگوریتم RL** (هفته ۲)

- طراحی و کدنویسی الگوریتم RL (Q-Learning، SARSA، DQN و غیره)
- تست منطق الگوریتم به صورت جداگانه
- تعریف توابع پاداش و فضاهای حالت/اقدام
- ✅ الگوریتم آماده برای یکپارچه‌سازی

**فاز ۳: آموزش ربات** (هفته‌های ۳-۴)

- یکپارچه‌سازی الگوریتم RL با سخت‌افزار ربات
- استفاده از داده سنسورها برای مشاهده حالت
- کنترل سروها بر اساس سیاست یادگرفته‌شده
- ✅ خزیدن خودکار به دست آمد!

### چیزهایی که با آن‌ها کار خواهید کرد

**سنسورها** (برای مشاهده حالت):

- سنسور حرکتی ۹ درجه آزادی (شتاب، چرخش، جهت‌گیری)
- ردیابی موقعیت و حرکت لحظه‌ای

**محرک‌ها** (برای اقدامات):

- ۲ موتور سروو برای کنترل پاها
- سرعت قابل تنظیم و حرکت نرم

**کد شما اینجا می‌رود:** `lib/Training/Training.cpp` - قالب آماده برای پیاده‌سازی RL شما!

> 📖 **برای نمونه کدهای RL به [EXAMPLES.fa.md](docs/EXAMPLES.fa.md) و برای جزئیات فنی به [PROJECT_SUMMARY.fa.md](docs/PROJECT_SUMMARY.fa.md) مراجعه کنید**

## شروع کار

### راه‌اندازی سریع (۵ دقیقه)

1. **نصب ابزارها**
   - [VSCode](https://code.visualstudio.com/) را نصب کنید
   - [افزونه PlatformIO](https://platformio.org/install/ide?install=vscode) را نصب کنید
2. **کلون و ساخت**

   ```bash
   git clone https://github.com/amirali-lll/crawling-bot-v2.git
   cd crawling-bot-v2
   pio run --target upload
   ```

3. **تنظیم ربات**

   - ربات را از طریق کلید On/Off واقع در زیر بدنه ربات روشن کنید.
   - - ربات یک نقطه اتصال ایجاد می کند به نام ESP32-AP-{number} (که نامبر همان شماره ی ربات شماست) به وای فای ربات متصل شوید و 1 تا 8 (12345678) را در فیلد رمز وارد کنید.
     - حالا پس از برقراری اتصال دستگاه شما با ربات، مجددا چک کنید که آیا آپلود ربات که با دستور (pio run --target upload) از قبل تلاش کرده بودید با موفقیت صورت گرفته است یا خیر اگر که آپلود انجام نشده بود دوباره با این دستور pio run --target upload ربات را برنامه ریزی کنید.
     - در صورتی که همه ی این مراحل را انجام داده باشید و ببینید که سیستم درحال آپلود است و آپلود با موفقیت به پایان برسد؛ تبریک میگم! این نشان می دهد که شما به ربات متصل شده اید و حالا قابلیت این را دارید که روی آن کدی را که نوشته اید بارگزاری کنید.(: 
   `

4. **شروع کدنویسی**
   - فایل `lib/Training/Training.cpp` را باز کنید
   - الگوریتم RL خود را پیاده‌سازی کنید
   - آپلود از طریق OTA: به WiFi ربات متصل شوید → `pio run --target upload`

## سخت‌افزار و معماری

**سخت‌افزار:** ESP32-S3، MPU9250 (۹-DOF)، ۲ سروو، نمایشگر OLED  
**نرم‌افزار:** کتابخانه‌های ماژولار (Display، AHRS، ServoControl، Network، Training)
**برق:** آداپتور ۱۲ ولت

تا زمان تعمیر سرووها، در `include/config.h` مقدار `ENABLE_SERVOS` برابر صفر است؛
در این حالت health check به سرووها فرمان نمی‌دهد و فقط IMU و نمایشگر را بررسی می‌کند.
